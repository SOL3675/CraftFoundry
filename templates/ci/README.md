# Install the CI template

Copy `workflows/fixtures.yml` to `.github/workflows/fixtures.yml` and both scripts from `scripts/` to `.github/scripts/`. Preserve the packaged fixtures, shared sources, templates, and root configuration layout.

See [CI setup](../../docs/ci.md) for existing EULA acceptance, pinned Node/Java, display prerequisites, evidence collection, and validation limits. A configured workflow alone does not establish a successful hosted game run.
